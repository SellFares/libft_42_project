# Libft

## Description
Libft is my first core project after completing 42 piscine.
It's my frist custom c library. The goal was to recreate standard c library functions from scratch which are included in the libc (part 1),
additional advanced functions useful in string and memory manipulation that are not part of the standard library such as 'ft_split', 'ft_itoa' and 'ft_sbustr' (part 2)
and linked list functions for manipulating linked list (part 3).
